# تطبيق الخدمة الذاتية (موبايل)

تطبيق React Native (Expo) للموظف ومدير الفرع والأدمن/مدير الموارد، مع خدمة API مستقلة. لا يعدّل أي ملف في مشروع الموقع الأصلي (HR).

## الهيكل
- `api/` خدمة Django جانبية (`mobile_api`) تستورد نماذج `backend/` من مشروع الموقع وتعرضها عبر `/m/v1/`.
- `app/` تطبيق Expo (Expo Router + TypeScript).
- `Dockerfile` لنشر الـ API على Dokploy (backend الموقع يُجلب وقت البناء، فلا نسخة مكررة منه).

## التطوير المحلي

الـ API يحتاج مجلد `backend` من مشروع الموقع (افتراضيًا `../HR/backend`، أو حدّده بـ `HR_BACKEND_DIR`) وملف `.env` في جذر هذا المجلد (انسخ `.env.example`).

```
run_api.bat            # المنفذ 8010، بيئة التطوير
```
الاختبارات (على SQLite مؤقتة، لا على قاعدة الإنتاج):
```
DATABASE_URL=sqlite:///test.sqlite3 python api/manage.py test mobile_api
```
التطبيق:
```
cd app
npm install
EXPO_PUBLIC_API_URL=http://<عنوان-الجهاز>:8010 npx expo start --lan
```
على الآيفون: Expo Go ثم مسح QR (الجوال على نفس الشبكة).

## النشر على Dokploy (mobil.alrsheed.net)

1. **تطبيق جديد** من هذا المستودع، نوع البناء **Dockerfile** (المسار `./Dockerfile`).
2. **Domain:** `mobil.alrsheed.net` — Port `7081` — HTTPS (Let's Encrypt).
3. **Environment:** انسخ المتغيرات من `.env.production.example` واملأ `SECRET_KEY` و`DATABASE_URL`
   (نفس قاعدة الموقع). `SECRET_KEY` مفتاح **جديد** خاص بالموبايل وليس مفتاح الموقع.
4. **Healthcheck:** المسار `/health/` (مضمَّن أيضًا في الصورة).
5. **Build args اختيارية:** `HR_REF` فرع/وسم الموقع الذي يُجلب منه الـ backend (الافتراضي `main`)،
   و`HR_CACHE_BUST` غيّر قيمته لإجبار جلب أحدث نسخة من الموقع عند إعادة البناء.

ملاحظات:
- الصورة **لا تنفّذ migrate** أبدًا. مخطط القاعدة يملكه الموقع وحده.
- بعد أي تعديل على نماذج الموقع أعد بناء خدمة الموبايل (غيّر `HR_CACHE_BUST`) لتتوافق النماذج.
- عامل gunicorn واحد افتراضيًا لأن قفل محاولات الدخول مخزّن في الذاكرة؛ للتوسع أضف `REDIS_URL`.
- تأكد أن Remote MySQL في Hostinger يسمح بعنوان سيرفر Dokploy (الموقع يتصل منه فهو مسموح غالبًا).

## بناء نسخة الأندرويد/iOS (EAS)

معرّف الحزمة `net.alrsheed.selfservice` في `app/app.json`، والعنوان الافتراضي للنسخ المنشورة
`https://mobil.alrsheed.net` (يمكن تجاوزه بـ `EXPO_PUBLIC_API_URL`).
```
cd app
npm i -g eas-cli
eas login
eas build -p android --profile preview      # APK للتجربة والتوزيع المباشر
eas build -p android --profile production   # AAB لمتجر Google Play
```
iOS يحتاج حساب Apple Developer. في النسخ المنشورة يُخفى حقل إعدادات الخادم من شاشة الدخول.

## الدخول
- الموظف: الرقم الوظيفي + رقم الهوية.
- المدير/الأدمن/مدير الموارد: اسم المستخدم أو رقمه + كلمة المرور (نفس حساب الموقع).
- حماية: قفل بعد 5 محاولات فاشلة لمدة 15 دقيقة (حسب المعرّف وعنوان IP)، ورسالة خطأ موحدة.

## الأدوار والشاشات
- **الموظف:** عرض بياناته (سلف، راتب، إجازات، غياب، إفادات) ورفع طلب إجازة أو سلفة ضمن مسار الموافقات.
- **مدير الفرع:** صندوق الموافقات (اعتماد/إرجاع) ضمن نطاق فروعه.
- **الأدمن/مدير الموارد:** لوحة تحكم وبيانات الموظفين (بحث وفلاتر وملف كامل) + الموافقات.
